For optimization models, check variable meaning and units, objective direction, resource and demand constraints, nonnegativity, and any integrality requirement. SECTION 3 · METHOD


Formulation: five steps

      1       Read the situation             mark every number, unit and keyword


      2       Set the decision variables     what is proportional to what?


      3       Write the objective function   one expression, maximize or minimize


      4       Write the constraints          one line per limit, plus X ≥ 0


      5       Assemble the model             objective, subject to, constraints

THE FINE PRINT


Assumptions and limits of LP

         Certainty — every coefficient is known, no probabilities

         Proportionality — double the input, double the output

         Additivity — the total is the sum of the parts

         Divisibility — fractions are allowed: 0.83 litres, or 2.4 aircraft


      Each one is a claim about the world — and each one is sometimes false.

import cvxpy as cp
 
# (1) Decision variables
X1 = cp.Variable()
X2 = cp.Variable()
 
# (2) Objective function: maximize total profit
z = cp.Maximize(20 * X1 + 50 * X2)
 
# (3) Constraints
constraints = [
    1.2 * X1 + 4 * X2 <= 240,   # assembly hours
    0.5 * X1 + X2 <= 81,        # inspection hours
    X2 <= 40,                   # chip supply
    X1 >= 0, X2 >= 0            # non-negativity
]
 
# (4) Formulate the problem
prob = cp.Problem(z, constraints)
 
# (5) Solve it (verbose=True prints the solver log)
prob.solve(solver='GLPK_MI', verbose=True)
 
# (6) Print the results
print("Optimal X1:", X1.value)
print("Optimal X2:", X2.value)
print("Max profit Z = 20X1 + 50X2:", prob.value)
print("Status:", prob.status)

A company ships a divisible commodity from factories A and B to customers North, Central, and East. Shipments are measured in **tons per week**. Minimize total transportation cost while meeting each customer's demand exactly. Following table describes the transportation costs from factory to customers.
| Factory | North (USD/ton) | Central (USD/ton) | East (USD/ton) | Supply capacity(tons) |
|---|---:|---:|---:|---:|
| A | 4 | 6 | 8 | 90 |
| B | 5 | 4 | 3 | 80 |
| Demand (tons) | 60 | 50 | 40 | |

Unused supply capacity is allowed. The A-to-North route can carry at most **40 tons**; the B-to-East route can carry at most **35 tons**. Other routes have no separate route limits.

## Your tasks
1. Define the decision variables, objective, and all constraints.
2. Solve the model and find the optimal solutions and value
3. Calculate the slack variables

import cvxpy as cp

# 1. Define the six shipment variables (tons per week).
x_AN = cp.Variable()
x_AC = cp.Variable()
x_AE = cp.Variable()
x_BN = cp.Variable()
x_BC = cp.Variable()
x_BE = cp.Variable()


# 2. Define the objective function (weekly transportation cost in dollars).
transport_cost = (4*x_AN + 6*x_AC + 8*x_AE
                  + 5*x_BN + 4*x_BC + 3*x_BE)

# 3. Define supply, demand, and route-capacity constraints.
supply_and_routes = [
    x_AN + x_AC + x_AE <= 90,
    x_BN + x_BC + x_BE <= 80,
