Google Colab 기본 조작법
이 문서는 Google Colaboratory(Colab)를 처음 사용하는 학생들을 위한 기본 사용법 안내입니다. 수업에서 캡처한

1. Colab이란? 
Colab은 브라우저에서 바로 Python 코드를 작성하고 실행할 수 있는 무료 환경입니다.
    장점: 별도 설치 없이 웹에서 사용, 무료 GPU/TPU 제공, Google Drive와 연동
    용도: 데이터 분석, 머신러닝 실습, 과제 제출 등

4. 셀
셀의 종류
  코드 셀: 왼쪽에 [] 가 보이며, 실행 후 [1] , [2] 처럼 실행 순서와 체크·소요 시간(예: 0초)이 표시됩니다. 코드
  아래에 출력이 나옵니다.
  텍스트 셀: 제목·설명 등 마크다운으로 작성하며, 실행하면 보기 좋게 렌더링됩니다.
  셀 조작: 각 셀 오른쪽에 위/아래 화살표(이동), 연필(편집), 휴지통(삭제), (더 보기) 아이콘이 있습니다.

4.1 코드 셀 (Code cell)
  Python 코드를 입력하고 실행하는 셀
  실행: 셀 왼쪽의 재생 버튼 클릭 또는 Shift + Enter
  여러 줄의 코드를 한 번에 실행할 수 있음




4.2 텍스트 셀 (Text / Markdown cell)
  제목, 설명, 수식을 적는 셀 (마크다운 형식)
  실행하면 렌더링된 문서처럼 보임
  코드 셀을 텍스트로 바꾸려면: 도구 모음에서 “텍스트” 선택 또는 메뉴 삽입 → 텍스트 셀

8. 런타임(실행 환경) 관리
런타임이란? 노트북 코드가 실제로 실행되는 Colab의 컴퓨터(서버)를 의미합니다. 즉, 여러분이 Colab에서 코드를 입
력하고 실행할 때, 코드나 데이터는 여러분의 컴퓨터가 아니라 Google에서 관리하는 Colab 전용 컴퓨터(서버)에 저장
되고 실행됩니다. Colab의 서버에서 해당 코드가 실행되는 공간이 바로 “런타임”입니다. 런타임 연결이란 여러분의 컴
퓨터와 Colab의 컴퓨터를 연결하는 것을 의미합니다. ### 8.1 런타임 유형 변경 (CPU / GPU / TPU)
   런타임 → 런타임 유형 변경
   CPU: CPU만 사용 (기본)

8.2 실행 중단, 세션 다시 시작

Page 12
실행 중단: 실행 중인 셀의 작업을 중단합니다. 세션 다시 시작: 현재 세션을 종료하고 새로운 세션을 다시 시작합니다.
컴퓨터를 재시동하는 것과 동일합니다.




세션(Session)이란?
Colab에서 “세션”은 사용자의 노트북이 연결되어 있는 일시적인 실행 환경(런타임)을 의미합니다. 즉, 여러분이 코드
를 실행할 수 있도록 만들어진 가상 컴퓨터 한 대라고 생각하면 됩니다. - 세션이 시작되면 Colab 서버에 컴퓨터가 실행
되고, 여기에 코드와 데이터, 변수, 설치한 패키지 등이 일시적으로 저장됩니다. - 세션이 중단(끊김)되면, 해당 환경에
서 작업한 내용(업로드 파일, 변수, 설치 패키지 등)은 모두 지워집니다.
- 노트북이 일정 시간 사용되지 않거나, 사용자가 “세션 중단/재시작”을 하면 세션이 초기화됩니다. - 따라서 중요한 파
일은 Google Drive 등에 저장하는 것이 안전합니다.

10. 노트북 저장 및 공유
  저장: Ctrl + S 또는 파일 → 저장
     기본적으로 Google Drive의 Colab 노트북에 자동 저장됩니다.
  공유: 오른쪽 상단 공유 버튼 — 링크나 이메일로 공유 가능 (편집/보기 권한 설정). 이를 통해서 공동 작업도 가능
  합니다.

12. 정리
  Colab은 브라우저만 있으면 Python 실습이 가능한 환경입니다.
  코드 셀과 텍스트 셀을 구분해서 사용하고, Shift + Enter 로 셀을 실행합니다.
  파일은 업로드 또는 Google Drive 연동으로 불러올 수 있습니다.
