Fixed Costs and Economies of Scale

Chapter 7  ·  Integer Programming
14
Fixed costs are a common source of economies of scale.

Unit cost C(X)/X decreases as output increases.

Add a binary variable Y and link it to X:
Y = 1 if X > 0 (producing)
       0 if X = 0 (not producing)

X ≤ cY, where c is production capacity
<Economies of Scale>

CAPITAL BUDGETING
Example 7-2: CVXPY Model and Solution

Chapter 7  ·  Integer Programming
19
F, W, M ∈ {0, 1}

Status: optimal  ·  Profit PV: 800.0
Factory: 1  ·  Warehouse: 0  ·  Machinery: 1
import cvxpy as cp

# 1. Binary project decisions
X1 = cp.Variable(boolean=True) # Factory
X2 = cp.Variable(boolean=True) # Warehouse
X3 = cp.Variable(boolean=True) # Machinery

# 2. Maximize present value of profit
objective = cp.Maximize(
    450*X1 + 200*X2 + 350*X3)

# 3. Annual funding constraints
constraints = [
    100*X1 + 150*X2 + 50*X3 <= 250,
    100*X1 + 50*X2 + 200*X3 <= 400,
    100*X1 + 50*X2 + 100*X3 <= 200
]

# 4. Define and solve the problem
problem = cp.Problem(objective, constraints)
problem.solve()

# 5. Results (profit in KRW 100 million)
print("Status:", problem.status)
print("Profit PV:", problem.value)
print("Factory:", round(float(X1.value)))
print("Warehouse:", round(float(X2.value)))
print("Machinery:", round(float(X3.value)))
