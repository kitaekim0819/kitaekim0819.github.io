Multi-criteria Decision Making

 MULTIPLE OBJECTIVES
 Choose among alternatives while considering
 several objectives at the same time.


 PARETO OPTIMAL SOLUTION
 No objective can improve without
 worsening at least one other objective.


 PARETO FRONT
 The set of Pareto optimal outcomes.           Both X and Y are to be maximized.
                                               D is on the frontier; C is dominated.

Methods for Multiple Criteria

 SCORING MODELS
 Assign criterion weights and compare weighted scores.


 DATA ENVELOPMENT ANALYSIS
 Use linear programming to evaluate relative efficiency.


 GOAL PROGRAMMING
 Minimize unwanted deviations from specified targets.
 Use priorities or a weighted sum of deviations.

Data Envelopment Analysis

 DEA uses linear programming to measure the relative efficiency of decision-making units (DMUs)
 with multiple inputs and outputs.


 COMPARABLE UNITS

 Examples include bank branches, hospitals,
 and schools with similar activities.


 RELATIVE BENCHMARK

 Compare each unit with combinations
 of observed peer units.

Goal Programming

 Goal programming minimizes unwanted deviations from specified target levels when several goals
 conflict.


 TWO APPROACHES

 Preemptive goal programming
 Protect higher-priority goals first.


 Weighted goal programming
 Combine penalized deviations in
 one objective function.
                                                        Targets may lie beyond the feasible region.

Weighted Goal Programming

 Assign a weight to each unwanted deviation and minimize their weighted sum in a single
 objective.


   Example goal                                                     Weight   Penalized deviation

   Profit ≥ KRW 10 million                                           0.5        D1: shortfall

   Advertising cost ≤ KRW 2 million                                  0.3         E2: excess

   Employment ≥ 50 people                                            0.2        D3: shortfall


 Minimize Z = 0.5D1 + 0.3E2 + 0.2D3
 Weights must account for the scales and units of the deviations.

Summary

 SCORING MODELS
 Simple and intuitive. Weights and ratings depend on judgment.

 DATA ENVELOPMENT ANALYSIS (DEA)
 Compares efficiency with observed peers. E = 1 alone does not rule out slacks.

 GOAL PROGRAMMING
 Strictly protects higher priorities, but may leave lower goals unmet.

 WEIGHTED GOAL PROGRAMMING
 Allows trade-offs in one LP. Results depend on weights and the units used.
