Hire skilled workers for 9,000 hours and apprentices for 12,000 hours

import cvxpy as cp
 
# 1. Decision variables
S = cp.Variable()
P = cp.Variable()
 
# 2. Objective: maximize total profit
objective = cp.Maximize(0.3 * S + 0.125 * P)
 
# 3. Constraints (note the == for equality)
constraints = [
    S + 0.5 * P == 15000,  # budget: spend all of it
    S <= 10000,            # skilled-worker hours
    P >= 12000,            # apprentice hours
    S >= 0,                # non-negativity
    P >= 0
]
 
# 4. Formulate and solve the problem
problem = cp.Problem(objective, constraints)
problem.solve()
 
# 5. Print the results
print("Status:", problem.status)
print("Maximum profit (Z):", problem.value)
print("Optimal S:", S.value)
print("Optimal P:", P.value)

import cvxpy as cp
 
# 1. Decision variables
R = cp.Variable()
E = cp.Variable()
 
# 2. Objective: maximize total floor area
objective = cp.Maximize(R + E)
 
# 3. Constraints
constraints = [
    200 * R + 400 * E <= 24000,  # construction cost
    R >= 105,                    # residential area
    E >= 30,                     # energy-control area
    R >= 0,                      # non-negativity
    E >= 0
]
 
# 4. Formulate and solve the problem
problem = cp.Problem(objective, constraints)
problem.solve()
 
# 5. Print the results
print("Status:", problem.status)
print("Maximum total area:", problem.value)
print("Optimal R:", R.value)
print("Optimal E:", E.value)

Example 3-5: input to output

OUTPUT

Status: unbounded
Maximum total profit: inf
Optimal X1: None
Optimal X2: None

Status is unbounded: the feasible region has no upper limit, so profit grows without bound

No finite optimum exists, so the variables have no value (None)

In practice this signals a missing constraint, such as a capacity or demand limit

Unbounded: a constraint is missing from the model

import cvxpy as cp
 
# 1. Decision variables
X1 = cp.Variable()
X2 = cp.Variable()
 
# 2. Objective: maximize total profit
objective = cp.Maximize(20 * X1 + 10 * X2)
 
# 3. Constraints
constraints = [
    X1 >= 1000,          # type A supply contract
    X2 >= 1000,          # type B supply contract
    X2 – X1 <= 500,      # company policy
    X1 >= 0,             # non-negativity
    X2 >= 0
]
 
# 4. Formulate and solve the problem
problem = cp.Problem(objective, constraints)
problem.solve()
 
# 5. Print the results
print("Status:", problem.status)
print("Maximum total profit:", problem.value)
print("Optimal X1:", X1.value)
print("Optimal X2:", X2.value)

Maximize  Z = 15X₁ + 50X₂    (was 20X₁ + 50X₂)

1.2X₁ + 4X₂  ≤  240    (assembly, hours)

0.5X₁ + X₂  ≤  81    (inspection, hours)

X₂  ≤  40    (chip supply, units)

X₁, X₂  ≥  0

The objective line is now parallel to the assembly constraint, so every point on segment BC is optimal (Z = 3,000)

Equality constraints are written with == in CVXPY
