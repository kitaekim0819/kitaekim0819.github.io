CVXPY
What is CVXPY?

Chapter 3  ·  Analysis of Linear Programming Models

An open-source, Python-embedded modeling language for convex optimization problems

You write the problem the way the math reads, not in the restrictive standard form a solver requires

Linear programs are a special case of convex problems, so CVXPY handles everything in this chapter

Model in CVXPY, then hand the model to a solver of your choice
Source: https://www.cvxpy.org/

CVXPY  ·  EXAMPLE 3-1
CVXPY: Input (Example 3-1)

Chapter 3  ·  Analysis of Linear Programming Models

import cvxpy as cp
 
# (1) Decision variables
X1 = cp.Variable()
X2 = cp.Variable()
 
# (2) Objective function: maximize total profit
z = cp.Maximize(20 * X1 + 50 * X2)
 
# (3) Constraints
constraints = [
    1.2 * X1 + 4 * X2 <= 240,   # assembly hours
    0.5 * X1 + X2 <= 81,        # inspection hours
    X2 <= 40,                   # chip supply
    X1 >= 0, X2 >= 0            # non-negativity
]
 
# (4) Formulate the problem
prob = cp.Problem(z, constraints)
 
# (5) Solve it (verbose=True prints the solver log)
prob.solve(solver='GLPK_MI', verbose=True)
 
# (6) Print the results
print("Optimal X1:", X1.value)
print("Optimal X2:", X2.value)
print("Max profit Z = 20X1 + 50X2:", prob.value)
print("Status:", prob.status)

EXAMPLE 3-2
Example 3-2: from model to code

Chapter 3  ·  Analysis of Linear Programming Models
FORMULATION

Decision variables

X₁ = kg of meat per person per day

X₂ = kg of vegetables per person per day

Objective function

Minimize  Z = 6000X₁ + 1000X₂

Constraints

300X₁ + 20X₂  ≥  66       (protein, g)

30X₁ + 10X₂  ≥  9       (iron, mg)

X₁, X₂  ≥  0

import cvxpy as cp
 
# 1. Decision variables
x1 = cp.Variable()
x2 = cp.Variable()
 
# 2. Objective: minimize total food cost
z = 6000 * x1 + 1000 * x2
objective = cp.Minimize(z)
 
# 3. Constraints: minimum nutrient requirements
constraints = [
    300 * x1 + 20 * x2 >= 66,   # protein >= 66 g
    30 * x1 + 10 * x2 >= 9,     # iron >= 9 mg
    x1 >= 0,                    # non-negativity
    x2 >= 0
]
 
# 4. Formulate and solve the problem
problem = cp.Problem(objective, constraints)
problem.solve()
 
# 5. Print the results
print("Status:", problem.status)
print("Minimum food cost:", problem.value, "won")
print("Meat (X1):", x1.value, "kg")
print("Vegetables (X2):", x2.value, "kg")

SUMMARY
Summary

Chapter 3  ·  Analysis of Linear Programming Models

Analyzing optimization problems with software

The basic algorithm: the simplex method

A Python-based modeling package: CVXPY

Many solvers exist, so choose one that suits your problem

Solvers differ in the problem classes and sizes they can handle

Solvers also search for the optimum differently, so their performance differs

Model once in CVXPY; switch solvers with a single argument
CVXPY IN SIX STEPS

1  Decision variables
x1 = cp.Variable()
2  Objective
z = cp.Maximize(...)  or  cp.Minimize(...)
3  Constraints
constraints = [c1, ..., cn]
4  Problem
prob = cp.Problem(z, constraints)
5  Solve
prob.solve()
6  Results
x1.value,  prob.value,  prob.status
