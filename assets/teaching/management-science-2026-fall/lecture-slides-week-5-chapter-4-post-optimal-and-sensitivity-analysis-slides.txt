Sensitivity Analysis – Objective Coefficients

Chapter 4  ·  Post-Optimal and Sensitivity Analysis
Mathematically, we can use the property that “the optimal solution is unchanged if the objective’s slope lies between the slopes of the two binding constraints” to find the range over which an objective coefficient can change without changing the optimal solution (the allowable range)

Slide 24
SENSITIVITY ANALYSIS
Sensitivity Analysis – Objective Coefficients

Chapter 4  ·  Post-Optimal and Sensitivity Analysis
Change in objective coefficient C2
Objective function: Z = 20X1 + C2X2
Slope of the objective function = -20/C2
Assembly (1.2 X1 + 4 X2 <= 240) slope: -1.2/4 = -0.3
Inspection (0.5 X1 + X2 <= 81) slope: -0.5/1 = -0.5
-0.5 <= -20/C2 <= -0.3 → 40 <= C2 <= 200/3 (≈66.7)
 
For 40 <= C2 <= 200/3, the optimal solution (X1=105, X2=28.5) does not change
Here, the optimal value Z = 20 ⨉ 105 + C2 ⨉ 28.5 = 28.5C2 + 2,100 (₩10,000) is proportional to C2

SENSITIVITY ANALYSIS
Sensitivity Analysis – Changes in the RHS

Chapter 4  ·  Post-Optimal and Sensitivity Analysis
When the right-hand side (RHS) changes
Changing the RHS shifts the constraint boundary, so the optimal solution itself changes
Small changes in the RHS are captured by the shadow price
However, when the change in the RHS is large, the shadow price itself changes
So, we need to check how far the RHS can change while the shadow price stays the same

SENSITIVITY ANALYSIS
Post-Optimal Analysis Using Sensitivity Analysis

Chapter 4  ·  Post-Optimal and Sensitivity Analysis
Deciding whether to add available hours (RHS change)
Adding 1 hour of daily labor in the assembly process costs ₩50,000. 
Based on the current sensitivity analysis, should we add labor to the assembly process?
If so, how much labor should we add?
(Hint) For 194.5 ≤ b1 ≤ 258.4, the assembly shadow price stays at ₩62,500/hour
Net profit per hour: ₩62,500 – ₩50,000 = ₩12,500
This shadow price is valid only for 194.5 ≤ b1 ≤ 258.4, so we can add at most 18.4 hours (258.4-240=18.4)
Total additional profit = ₩12,500/hour × 18.4 hours = ₩230,000
