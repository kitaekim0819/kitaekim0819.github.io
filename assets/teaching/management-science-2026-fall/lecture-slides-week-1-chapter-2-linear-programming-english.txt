THE CORE IDEA


Optimization

         Alternatives — what could we do?

         Preferences and constraints — which is better, and what is allowed?

         Optimal solution — the best alternative that satisfies every constraint



      Alternatives and preferences both linear → a linear optimization model

DEFINITION


Linear programming

         Building a linear optimization model of a decision, and using it to choose the best option

         Simplex method · Dantzig, 1947

         Interior-point method · Karmarkar, 1984

         The most widely used analytical tool in production, logistics and finance




      “Programming” here means planning — the word predates computer programming.

SECTION 2 · OVERVIEW


Every LP model has three parts

         Decision variables — what are we deciding?

         Objective function — what are we trying to do?

         Constraints — what are the limits?



      Miss one, or write a nonlinear line, and it is not a linear program.

SECTION 3 · METHOD


Formulation: five steps

      1       Read the situation             mark every number, unit and keyword


      2       Set the decision variables     what is proportional to what?


      3       Write the objective function   one expression, maximize or minimize


      4       Write the constraints          one line per limit, plus X ≥ 0


      5       Assemble the model             objective, subject to, constraints

STEP 1


Read the situation

         Mark every number

         Mark every unit — won/case, hours/unit, %

         Mark every keyword — available, at most, at least, exactly

         Find the goal sentence — usually the last one

         Ask: what is being decided, and by whom?


      Most formulation errors are reading errors.

STEP 2


Set the decision variables

         Ask what is proportional to what

         Follow the units

                    “30,000 won per unit” → the coefficient is 30,000

         Read the denominator

                    won per case → cases are the variable

                    risk per 10,000 won → money is the variable


      No unit, no variable.

STEP 3


Write the objective function

         Find the goal sentence → maximize or minimize

         One coefficient for each variable, added together

                    8,000 won/case × X₁ cases = 8,000X₁ won

                    6,000 won/case × X₂ cases = 6,000X₂ won

         Every term in the same unit — and exactly one objective


                Maximize                8,000X₁ + 6,000X₂

STEP 5


Assemble the model

   X₁, X₂ = cases of knives, forks produced next week

   Maximize                             8,000X₁ + 6,000X₂
   subject to                           0.2X₁ + 0.4X₂ ≤ 700
                                        0.5X₁ + 0.25X₂ ≤ 1,000
                                        X₁ ≥ 0, X₂ ≥ 0


      Variables defined · one objective · one line per limit · non-negativity · all linear


   That is the whole method. Five cases follow — only the story changes.

Example 2-1 — optimal solution


   (X₁, X₂) = (1,500, 1,000)
   Maximum weekly profit 18,000,000 won

THE FINE PRINT


Assumptions and limits of LP

         Certainty — every coefficient is known, no probabilities

         Proportionality — double the input, double the output

         Additivity — the total is the sum of the parts

         Divisibility — fractions are allowed: 0.83 litres, or 2.4 aircraft


      Each one is a claim about the world — and each one is sometimes false.
